Ferramenta de Poligonal

Preencha a tabela com o ponto inicial e os dados de distância/azimute de cada segmento — ou cole direto de uma planilha Excel — e o Zonea desenha a poligonal, calcula área, perímetro e verifica o erro de fechamento automaticamente.

SIRGAS 2000 · UTM Zona 23S
⚠️ Ferramenta de apoio, não substitui ART/RRT: os resultados desta calculadora são uma pré-visualização para conferência. Para submissão oficial à prefeitura, a poligonal deve ser assinada por profissional habilitado (CREA/CAU), conforme a legislação do município.

Antes de Começar: Verifique o Datum do Documento

Esta ferramenta assume coordenadas em SIRGAS 2000 / UTM zona 23S. Confira o sistema de referência do memorial descritivo ou planta que você recebeu antes de preencher os dados abaixo.

Passo Verificação
1 Confira no documento qual é o Datum (sistema de referência): SIRGAS 2000 (referencial geocêntrico para as Américas) ou WGS84 (sistema global). Se não for nenhum dos dois, vá direto ao passo 4.
2 Se for SIRGAS 2000, confirme que as coordenadas estão referenciadas ao Meridiano Central 45° WGr (fuso UTM 23S — o padrão usado por esta ferramenta).
3 Se for WGS84, as coordenadas precisam ser convertidas para SIRGAS 2000 antes de preencher o formulário abaixo (veja o passo 4).
4 Se o Datum for antigo (ex.: Córrego Alegre, SAD69) ou WGS84, acione a PRODABEL via SDM para realizar a conversão para SIRGAS 2000.
ℹ️ Se o memorial descritivo trouxer as coordenadas em Latitude/Longitude (graus, minutos e segundos) em vez de UTM, converta para E/N antes de preencher a ferramenta abaixo.

Reconstituir a Poligonal a partir do Memorial Descritivo

A primeira linha é o ponto inicial (coordenadas E, N). As linhas seguintes são os segmentos do caminhamento (Azimute + Distância) — E/N são calculados automaticamente. Digite célula por célula ou cole direto de uma planilha Excel.

# Azimute Distância (m) E (m) N (m)

Formatos de azimute aceitos: 189°1'24.32" ou decimal 189.5. Ao colar do Excel, a ferramenta reconhece 2, 4 ou 6 colunas (incluindo o formato completo do memorial: Vértice Inicial, Vértice Final, Azimute, Distância, E, N).
